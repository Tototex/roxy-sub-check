NFC-friendly membership verification page for WooCommerce Subscriptions.

== Description ==

Roxy Subscription Check supports:

* Membership verification page
* NFC and QR workflows
* Per-subscription member photos
* Scan logging
* My Account photo upload
* GitHub auto-updates

== Installation ==

1. Upload the plugin ZIP to WordPress.
2. Activate the plugin.
3. Use /member-check/?sub=XXXXX for verification.
